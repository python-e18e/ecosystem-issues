# Python ecosystem issues

This is the first [python-e18e](https://github.com/python-e18e) repository: a shared tracker for practical Python ecosystem cleanups, speedups, and modern alternatives. It follows [e18e's cross-project issue tracker](https://github.com/e18e/ecosystem-issues).

Use an issue to describe one project, its current tooling or dependency, the proposed change, and the evidence needed to verify it. The repository is for coordinating contributions across projects; code and package data live in their own repositories.

## Working on an opportunity

1. Reproduce the current behavior or cost, and check the project's supported Python versions.
2. Check whether maintainers welcome the change and follow their contribution guidelines.
3. Propose the smallest useful change upstream, with before/after checks.
4. Link the upstream issue or pull request here, and update the outcome.

Start with the [opportunity template](.github/ISSUE_TEMPLATE/opportunity.md). Package replacement candidates belong in [module-replacements](https://github.com/python-e18e/module-replacements) after the evidence is clear.
